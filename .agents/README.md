# Agentic Awesome Skills (AAS) for Portfolio 2

This directory contains the Agentic Awesome Skills framework for Antigravity and AI coding agents.

## Directory Layout

- `skills/`: The **currently active** skills exposed to the agent.
- `skills_library/`: The full backing store of **3,100+ skills** from [sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills).
- `data/`: Bundle definitions (`editorial-bundles.json`) and catalog indices.
- `docs/`: User guides, bundles documentation, and troubleshooting.
- `tools/`: Bundle expansion tools and scripts.
- `CATALOG.md`: Complete searchable Markdown catalog of all 3,100+ skills.
- `skills_index.json`: Machine-readable skills index.
